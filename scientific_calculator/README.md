# Python Terminal Calculator

This is a basic terminal-based calculator I built while learning Python. It started out as a simple arithmetic script and I expanded it to handle trigonometry and some math constants.

## What it can do:

* Standard math: Add, Subtract, Multiply, Divide, and Powers.
* Trig section: Sine, Cosine, and Tangent (automatically converts your degree inputs to radians).
* Smart inputs: Instead of just typing numbers, you can type constants like `pi`, `e`, `tau`, `phi`, `g`, or `inf`.
* Basic safety: It will print an error if you try to divide by 0.

## How to run it:

```bash
python main.py
```
