# Python Projects

A collection of my terminal-based Python projects organized into separate directories.

## Projects

* **[Dungeon Game](./dungeon_game/)** - A text-based RPG featuring interactive turn-based combat and a merchant trading system.
* **[Scientific Calculator](./scientific_calculator/)** - A terminal calculator that handles basic arithmetic, trigonometry, and math constants.

## Setup
The repository includes a root `.gitignore` file to keep compilation cache files (`__pycache__/`) out of the source control history.
