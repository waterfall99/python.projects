# Python Dungeon Explorer

A simple, text-based dungeon crawler I made while learning Python.

I started this project to practice Object-Oriented Programming (OOP) and get comfortable managing a functional game loop. It is completely text-based, focusing entirely on logic, code structure, and player decisions.

## Features
*   **Player Setup:** Built using a dedicated `Player` class that tracks stats like name, health (`hp`), and an interactive inventory.
*   **Core Game Loop:** Controlled by a continuous `while` loop that handles exploration, inputs, and real-time state changes.
*   **Hidden Secrets:** Keep an eye out for a hidden gold coin hidden somewhere within the code.

## Getting Started
To run the game locally, you just need Python installed.

1. Clone or download the repository.
2. Open your terminal or command prompt in the project folder.
3. Run the following command:
```bash
python main.py
```
